1. Install Prerequisites
	•	Install Node.js 18+.
	•	Install pnpm (npm install -g pnpm).

⸻

2. Clone Inbox Zero Repo

git clone https://github.com/elie222/inbox-zero.git
cd inbox-zero
pnpm install



⸻

3. Create docker-compose.yml (local services)

version: '3.8'

services:
  postgres:
    image: postgres
    restart: always
    environment:
      POSTGRES_USER: inbox
      POSTGRES_PASSWORD: inboxpassword
      POSTGRES_DB: inboxdb
    ports:
      - "5432:5432"

  redis:
    image: redis
    restart: always
    ports:
      - "6379:6379"

✅ Save this in the root of your project folder as docker-compose.yml.

⸻

4. Start Docker Containers

docker-compose up -d

✅ This spins up local Postgres and Redis servers instantly.

⸻

5. Set Up .env.local File

# .env.local
DATABASE_URL=postgresql://inbox:inboxpassword@localhost:5432/inboxdb
REDIS_URL=redis://localhost:6379
OPENAI_API_KEY=sk-xxxxxxx  # your OpenAI key
GOOGLE_CLIENT_ID=xxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=xxxx
NEXT_PUBLIC_GOOGLE_REDIRECT_URI=http://localhost:3000/api/auth/callback
JWT_SECRET=some-random-secret-string
NODE_ENV=development

✅ Modify with your real Google OAuth credentials.

http://localhost:3000/api/auth/callback
	•	Download credentials and plug into your .env.local.

7. Run Inbox Zero Locally

pnpm dev

✅ Your app runs on http://localhost:3000.
	•	Go to browser → localhost:3000

📄 Create a New File: start-local.sh

#!/bin/bash

echo "🚀 Starting Inbox Zero Local Development Environment..."

# Step 1: Start Docker containers
echo "🐳 Starting Docker containers for Postgres and Redis..."
docker-compose up -d

# Step 2: Wait for containers to be ready
echo "⌛ Waiting 5 seconds for Postgres and Redis to be fully available..."
sleep 5

# Step 3: Run local development server
echo "🖥️ Starting Inbox Zero dev server (pnpm dev)..."
pnpm dev &

# Step 4: Open browser automatically
sleep 3
echo "🌐 Opening http://localhost:3000 in your default browser..."
if which xdg-open > /dev/null
then
  xdg-open http://localhost:3000
elif which open > /dev/null
then
  open http://localhost:3000
elif which start > /dev/null
then
  start http://localhost:3000
fi

# Final confirmation
echo "✅ All systems started. Inbox Zero is running at http://localhost:3000"

🛠 2. Small Bash Script to Toggle Between Free Mode and Pro Mode

📄 toggle-plan-mode.sh

Create this file in your project root:

#!/bin/bash

MODE=$1

if [ "$MODE" == "pro" ]; then
    echo "Setting default plan to PRO mode..."
    sed -i '' 's/@default("FREE")/@default("PRO")/' prisma/schema.prisma
elif [ "$MODE" == "free" ]; then
    echo "Setting default plan to FREE mode..."
    sed -i '' 's/@default("PRO")/@default("FREE")/' prisma/schema.prisma
else
    echo "Usage: ./toggle-plan-mode.sh [pro|free]"
    exit 1
fi

echo "✅ Schema updated. Now run:"
echo "   pnpm prisma migrate dev --name toggle-plan-mode"

# 🧹 2. **One-Line Database Reset Command**

If you ever want to **start fresh** with a clean local Postgres database (wipe all old emails, tasks, drafts):

Here's a safe one-line Docker Postgres reset:

```bash
docker-compose down && docker volume prune -f && docker-compose up -d

✅ What it does:
	•	docker-compose down → Stops all containers (Postgres, Redis).
	•	docker volume prune -f → Deletes all stored volumes (this clears Postgres database files permanently).
	•	docker-compose up -d → Rebuilds fresh, brand new empty Postgres and Redis containers.

⸻

📢 IMPORTANT NOTE:
